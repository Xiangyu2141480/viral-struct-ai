# Demo Case 设计

## 推荐主案例：便携咖啡杯

### 样例视频结构

```txt
0-2s    反常识 Hook
2-4s    痛点展示
4-8s    卖点 1 + 卖点 2
8-12s   对比 / 证明
12-15s  CTA
```

### 新商品信息

```txt
商品：便携咖啡杯
目标用户：通勤上班族
使用场景：地铁、开车、办公室
卖点：保温 8 小时、不漏水、单手开盖、可放车载杯架
CTA：通勤党想喝热咖啡，就选它
```

### 用户素材

故意只提供：

```txt
产品图 1 张
手持图 1 张
商品介绍文案 1 段
```

故意缺少：

```txt
开头强视觉镜头
使用过程视频
普通杯 vs 便携杯对比镜头
结尾 CTA 图
```

### 系统应展示

```txt
1. 样例结构抽取结果
2. 新内容映射结果
3. 缺口识别表
4. 补全策略：标题卡、裁切推近、对比卡、CTA 卡
5. 脚本、分镜、时间线
6. 可播放 demo
```
