# Demo Case 设计

## 推荐主案例：康师傅冰红茶

### 样例视频结构

```txt
0-2s    反常识 Hook
2-4s    痛点展示
4-8s    卖点 1 + 卖点 2
8-12s   对比 / 证明
12-15s  CTA
```

### 新商品信息

```txt
商品：康师傅冰红茶
目标用户：夏季通勤和校园人群
使用场景：午后高温、运动后、饭后解腻
卖点：冰爽解腻、柠檬茶香、大瓶畅饮、冷藏口感更好
CTA：想要冰爽解腻，就来一瓶康师傅冰红茶
```

### 用户素材

故意只提供：

```txt
瓶身主图 1 张
动感冰爽图 1 张
组合包装图 1 张
商品介绍文案 1 段
```

故意缺少：

```txt
开头强视觉镜头
完整开盖畅饮过程
普通饮料 vs 冰红茶对比镜头
结尾 CTA 图
```

### 系统应展示

```txt
1. 样例结构抽取结果
2. 新内容映射结果
3. 缺口识别表
4. 补全策略：标题卡、裁切推近、对比卡、CTA 卡
5. 脚本、分镜、时间线
6. 可播放 demo
```
