# 产品规格

## 页面流

```txt
/             首页
/create       创建项目
/analyze      样例视频分析
/graph        结构图谱
/adapt        新内容与素材输入
/gaps         素材缺口与补全
/result       脚本 / 分镜 / 时间线 / demo
```

## 用户故事

```txt
作为创作者，我可以上传一条爆款样例视频，系统帮我拆出结构。
作为创作者，我可以输入新商品和少量素材，系统判断是否足够。
作为创作者，我可以看到缺少哪些镜头，并选择补全策略。
作为创作者，我可以生成脚本、分镜、时间线和视频 demo。
作为创作者，我可以调整 hook、节奏、卖点顺序和包装风格。
```
