# 任务拆分：按拿满分设计

## 项目主线

```txt
样例理解 → 结构抽取 → 素材适配 → 缺口补全 → 时间线生成 → 可视化验证 → 人工调整
```

## P0 必须完成

### T01 样例视频输入与基础解析

目标分数：基础闭环 5/5。

验收标准：

```txt
支持上传样例视频。
展示时长、比例、帧率、分辨率、封面、关键帧、镜头数、字幕/语音概览。
支持 ASR 失败时手动粘贴字幕 fallback。
```

接口：

```txt
POST /api/videos/upload
POST /api/videos/:id/analyze
```

前端页面：

```txt
/analyze
```

---

### T02 结构拆解

目标分数：结构拆解 8-10/10。

必须完成三类结构：

```txt
脚本结构：Hook / 痛点 / 卖点 / 证明 / CTA
节奏结构：镜头切换频率、段落快慢、高潮位置
包装结构：字幕密度、标题条、卖点卡、转场、封面风格
```

输出：

```txt
ViralStructureGraph
```

前端页面：

```txt
/graph
```

---

### T03 新内容与素材输入

目标分数：基础闭环 + 真实素材适配。

验收标准：

```txt
支持输入商品名、目标用户、使用场景、卖点、CTA。
支持上传图片 / 视频 / 文案至少一种。
生成 AssetCard，并给出适合槽位。
```

前端页面：

```txt
/adapt
```

---

### T04 结构迁移与结果生成

目标分数：结构迁移 8-10/10。

结果至少输出两项，建议输出四项：

```txt
脚本
分镜
时间线草案
可播放 demo
```

接口：

```txt
POST /api/timeline/generate
POST /api/render
```

---

### T05 素材缺口识别

目标分数：素材缺口识别 6-8/8。

验收标准：

```txt
每个结构槽位都有 requiredAsset。
每个用户素材都有 capabilities。
系统输出 matched / partial / missing。
说明缺口原因和影响。
```

示例缺口：

```txt
缺少开头吸引镜头
缺少商品特写
缺少使用过程镜头
缺少对比镜头
缺少结尾 CTA 镜头
```

---

### T06 素材缺口补全

目标分数：素材补全 9-12/12。

至少实现一种，建议实现三种：

```txt
包装补全：标题条、卖点卡、CTA 卡、对比卡
文案 / 字幕补全：用强文案代替缺失画面
现有素材重组复用：裁切、放大、重复、镜头重排
```

可选加分：

```txt
AIGC 生成封面图 / 背景图 / 补充画面
```

---

### T07 迁移过程可视化

目标分数：迁移过程可视化 8-10/10。

必须展示：

```txt
样例抽取了什么结构
结构如何映射到新内容
哪些槽位出现素材缺口
最终如何补全并生成结果
```

推荐组件：

```txt
StructureGraph
MappingTable
GapBoard
TimelineView
QualityReport
```

---

### T08 结果可验证

目标分数：最终展示 8-10/10。

至少提供：

```txt
新视频 demo
或分镜 / 时间线可视化
或样例结构与新结果对比
```

建议全部提供。

## P1 冲分能力

### T09 画面包装生成

目标分数：6-8/8。

实现至少两项：

```txt
字幕样式 / 排版建议
标题条 / 卖点卡片生成
封面文案 / 封面方案生成
转场建议
贴纸 / 强调元素推荐
```

---

### T10 多版本生成

目标分数：3-4/4。

版本：

```txt
高点击版
高转化版
高质感版
高节奏版
```

实现方式：

```txt
改变 hook 强度、卖点顺序、节奏、字幕密度、包装风格。
```

---

### T11 真实素材适配

目标分数：6-8/8。

实现：

```txt
素材分类
高光片段筛选
商品 / 人物 / 场景识别
适合开头 / 中段 / 结尾的片段推荐
```

最低可行实现：

```txt
spatial frame + temporal frames + LLM/VLM 描述 + slot recommendation
```

---

### T12 人工可调

目标分数：6-8/8。

支持修改：

```txt
hook 方式
卖点顺序
包装风格
视频节奏
结尾表达
```

---

### T13 自然语言编辑

加分项。

示例：

```txt
“开头更抓人一些” → 提高 hookStrength，改写 hook，增加前 3 秒切镜。
“把商品信息提前” → 将 selling_point 移动到 hook 后。
```

输出：

```txt
timeline patch
```
