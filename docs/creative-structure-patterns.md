# Creative Structure Patterns

This document captures reusable creative structure patterns that can be handed
from Asset Manager to Video Agent, GapRepair, HyperFrames, or AIGC planning.
It is not a rendered-video claim and it does not introduce a visual motif score.

## Kinetic Assembly Pattern

The MacBook Neo source example uses a kinetic product-language pattern:

- `dynamic_entry`: an object enters the frame with energy.
- `impact_beat`: the entry lands on a visible rhythm beat.
- `assembly_reveal`: components or parts imply assembly into a whole.
- `activation_moment`: the product state changes from inert to active.
- `lockup_transition`: the ending locks into a clean product/CTA frame.

The transferable structure is not the literal object, brand, keyboard, or
computer imagery. The transferable value is the motion grammar: object entry,
impact, assembly, activation, and clean lockup.

## Kangshifu Iced Tea Equivalent

For Kangshifu iced tea, the equivalent motion vocabulary is beverage-native:

- `ice_cube_drop`: replaces a falling object with an ice cube entering a cold
  drink scene.
- `open_cap`: replaces assembly touch with a real user opening the bottle.
- `pour_to_cup`: converts component assembly into beverage flow and reveal.
- `drink_neck_down`: validates product use without face-dependent footage.
- `bottle_rotation`: gives product-label reveal and motion without copying the
  source visual.
- `lineup_sweep`: creates pack or SKU reveal with a lateral sweep.
- `clean_cta_end_frame`: locks the sequence into a readable product + CTA end.
- `hyperframes_benefit_card_drop`: covers missing action with a benefit card
  animation when real footage is unavailable.

## Handoff Boundary

Asset Manager may output:

- transition needs
- required motion ingredients
- asset transition affordances
- transition coverage observations
- downstream handoff briefs

Asset Manager does not:

- render frames or video
- call external generation models
- decide the final edit
- claim a completed MP4
- copy source product visuals
- compute a visual motif score

## Demo Defense Talking Points

1. The source pattern is abstracted into motion grammar, not copied as imagery.
2. Kangshifu equivalents are beverage-specific and can be satisfied by ordinary
   user footage, prompt-ready AIGC briefs, or HyperFrames cards.
3. Weak or missing motion ingredients remain explicit observations so the demo
   does not pretend that a product still image can cover usage or transition
   evidence.
4. The handoff is useful for downstream systems while staying honest: it is a
   planning contract, not current rendered output.
