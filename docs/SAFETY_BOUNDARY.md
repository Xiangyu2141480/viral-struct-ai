# 安全边界

## 1. 不复制样例内容

系统只迁移：

```txt
结构
节奏
包装方式
表达策略
```

系统不迁移：

```txt
原视频人物肖像
原视频原文案
原视频品牌元素
原视频音乐原片段
原视频受版权保护的画面
```

## 2. 营销文案事实性

所有以下表达必须有证据来源：

```txt
功效
价格
优惠
认证
销量
排名
医疗 / 金融 / 教育承诺
```

无证据则降级表达或要求用户确认。

## 3. 素材版权

```txt
用户上传素材默认视为用户拥有使用权。
系统不主动移除水印。
系统不帮助复刻他人视频结果。
```

## 4. API Key 安全

```txt
API Key 只允许保存在服务端环境变量。
前端不得暴露模型密钥。
日志不得打印密钥。
提交前必须检查 .env 未入库。
```

## 5. AIGC 标识

```txt
如果使用 AIGC 生成封面、背景图、补充画面，应在项目说明和 demo 中标记。
```

## 6. 禁止内容

```txt
违法违规
仇恨歧视
暴力血腥
色情低俗
诈骗诱导
虚假医疗 / 金融承诺
冒充他人或品牌授权
```
