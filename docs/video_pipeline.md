              │  - 候选集 S = ∅       │
              │  - 记忆缓冲 M = ∅     │
              │  - Reward 历史 Hr = ∅ │
              └──────────────────────┘
                          │
                          ▼
        ┌─────────────────────────────────────┐

   ┌──────────────────────┐                │  │

   │  → (thought, score)   │                │  │
   │  参考 Hr 保持一致性    │                │  │
   └──────────────────────┘                │  │
              │                            │  │
              ▼                            │  │
