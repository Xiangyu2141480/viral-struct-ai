# Demo Cases / 可展示案例设计

## 1. 主案例：便携咖啡杯

这是冲奖版本的固定演示 case。它的价值是：素材故意不完整，能稳定展示“素材缺口识别 + 补全策略”，比素材齐全的 case 更容易拿分。

### 1.1 样例视频结构

```txt
0-2s    反常识 Hook：通勤路上热咖啡为什么总变难喝？
2-4s    痛点展示：普通杯漏水、变凉、拿取不方便。
4-8s    卖点推进：保温 8 小时、不漏水、单手开盖。
8-12s   对比 / 证明：包里倒置、车载杯架、办公室使用。
12-15s  CTA：通勤党想喝热咖啡，就选它。
```

### 1.2 新商品信息

```txt
商品：便携咖啡杯
目标用户：通勤上班族
使用场景：地铁、开车、办公室
卖点：保温 8 小时、不漏水、单手开盖、可放车载杯架
CTA：通勤党想喝热咖啡，就选它
```

### 1.3 用户素材

故意只提供：

```txt
产品图 1 张
手持图 1 张
商品介绍文案 1 段
```

故意缺少：

```txt
开头强视觉镜头
使用过程视频
普通杯 vs 便携杯对比镜头
结尾 CTA 镜头
```

## 2. 主案例必须展示的证据

| 展示环节 | 评委看到什么 | 对应得分点 |
|---|---|---|
| 样例解析 | 时长、镜头数、封面、字幕/语音概览 | 样例输入与基础解析 |
| 结构图谱 | Hook、痛点、卖点、证明、CTA、节奏、包装 | 结构拆解能力 |
| 新内容输入 | 商品、用户、场景、卖点、CTA、素材列表 | 新内容与素材输入 |
| 槽位匹配 | 每个结构槽位对应素材状态 | 素材缺口识别 |
| 缺口说明 | 缺什么、为什么缺、影响哪段表达 | 素材缺口识别 |
| 补全策略 | 标题卡、卖点卡、对比卡、CTA 卡、字幕补全、裁切复用 | 素材缺口补全 |
| 结果输出 | 脚本、分镜、时间线、包装建议、preview/demo | 结构迁移生成与结果验证 |
| 过程可视化 | 样例结构 -> 映射 -> 缺口 -> 补全 -> 结果 | 迁移过程可视化 |

## 3. 预期输出

### 脚本

```txt
Hook：早八通勤，为什么你的咖啡到公司就凉了？
痛点：普通杯容易漏、保温短、开盖不方便。
卖点：这只杯子保温 8 小时，倒置不漏，单手就能开。
证明：放进包里、车载杯架、办公室桌面三种场景连续展示。
CTA：通勤党想一路喝到热咖啡，就选这只便携咖啡杯。
```

### 分镜

```txt
S01 标题卡 + 产品局部放大：早八咖啡到公司就凉？
S02 手持图裁切放大：普通杯尴尬痛点。
S03 产品图 + 卖点卡：保温 8 小时 / 不漏水 / 单手开盖。
S04 对比卡：普通杯 vs 便携杯。
S05 CTA 卡 + 产品图：通勤党热咖啡解决方案。
```

### 时间线草案

```txt
0.0-2.0s   Hook card + product zoom
2.0-4.0s   Pain point card + handheld asset
4.0-8.0s   Selling points cards + product image
8.0-12.0s  Comparison card + reused asset
12.0-15.0s CTA card + product hero
```

### 包装建议

```txt
字幕：高密度短句，关键词加粗。
标题条：前 2 秒大标题，制造通勤痛点。
卖点卡：三连卡片，每张只承载一个卖点。
转场：卖点卡之间用快切，CTA 前放慢 0.5 秒。
封面：产品居中 + “早八咖啡不再凉”。
```

## 4. 备选案例

| 案例 | 适合展示 |
|---|---|
| 桌面收纳盒 | 对比前后、包装补全、封面文案 |
| 降噪耳机 | 场景切换、卖点证明、多版本 |
| 迷你筋膜枪 | 使用过程缺口、字幕补全、节奏增强 |
| 护肤品旅行装 | 包装风格、封面方案、卖点顺序调整 |

## 5. 答辩用一句话

```txt
我们故意给系统不完整素材，让评委看到它不是简单生成脚本，而是能判断哪些结构槽位缺素材，并用包装、字幕和素材复用把视频表达补齐。
```
