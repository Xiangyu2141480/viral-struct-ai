# Demo Cases / 可展示案例设计

## 1. 主案例：康师傅冰红茶

这是冲奖版本的固定演示 case。它的价值是：素材故意不完整，能稳定展示“素材缺口识别 + 补全策略”，比素材齐全的 case 更容易拿分。

### 1.1 样例视频结构

```txt
0-2s    场景 Hook：这么热的午后，第一口要够冰爽。
2-4s    痛点展示：普通饮料甜腻、不解渴、不适合饭后。
4-8s    卖点推进：冰爽解腻、柠檬茶香、大瓶畅饮。
8-12s   对比 / 证明：冷藏、开盖、饮用和场景化展示。
12-15s  CTA：想要冰爽解腻，就来一瓶康师傅冰红茶。
```

### 1.2 新商品信息

```txt
商品：康师傅冰红茶
目标用户：夏季通勤和校园人群
使用场景：午后高温、运动后、饭后解腻
卖点：冰爽解腻、柠檬茶香、大瓶畅饮、冷藏口感更好
CTA：想要冰爽解腻，就来一瓶康师傅冰红茶
```

### 1.3 用户素材

故意只提供：

```txt
瓶身主图 1 张
动感冰爽图 1 张
组合包装图 1 张
商品介绍文案 1 段
```

故意缺少：

```txt
开头强视觉镜头
完整开盖畅饮过程
普通饮料 vs 冰红茶对比镜头
结尾 CTA 镜头
```

## 2. 主案例必须展示的证据

| 展示环节 | 评委看到什么 | 对应得分点 |
|---|---|---|
| 样例解析 | 时长、镜头数、封面、字幕/语音概览 | 样例输入与基础解析 |
| 结构图谱 | Hook、痛点、卖点、证明、CTA、节奏、包装 | 结构拆解能力 |
| 新内容输入 | 商品、用户、场景、卖点、CTA、素材列表 | 新内容与素材输入 |
| 槽位匹配 | 每个结构槽位对应素材状态 | 素材缺口识别 |
| 缺口说明 | 缺什么、为什么缺、影响哪段表达 | 素材缺口识别 |
| 补全策略 | 标题卡、卖点卡、对比卡、CTA 卡、字幕补全、裁切复用 | 素材缺口补全 |
| 结果输出 | 脚本、分镜、时间线、包装建议、preview/demo | 结构迁移生成与结果验证 |
| 过程可视化 | 样例结构 -> 映射 -> 缺口 -> 补全 -> 结果 | 迁移过程可视化 |

## 3. 预期输出

### 脚本

```txt
Hook：这么热的午后，第一口就要够冰爽。
痛点：普通饮料甜腻，不够解渴，也不适合饭后。
卖点：康师傅冰红茶冰爽解腻，柠檬茶香更清爽，大瓶畅饮更过瘾。
证明：瓶身主图、动感冰爽图和组合包装图连续展示冷藏口感。
CTA：想要冰爽解腻，就来一瓶康师傅冰红茶。
```

### 分镜

```txt
S01 标题卡 + 瓶身局部放大：热到没胃口？
S02 动感冰爽图裁切放大：第一口冰爽降温。
S03 瓶身主图 + 卖点卡：冰爽解腻 / 柠檬茶香 / 大瓶畅饮。
S04 对比卡：普通饮料 vs 冰红茶。
S05 CTA 卡 + 产品图：夏日冰爽解腻选择。
```

### 时间线草案

```txt
0.0-2.0s   Hook card + bottle zoom
2.0-4.0s   Refresh card + splash asset
4.0-8.0s   Selling points cards + product image
8.0-12.0s  Comparison card + reused lifestyle asset
12.0-15.0s CTA card + product hero
```

### 包装建议

```txt
字幕：高密度短句，关键词加粗。
标题条：前 2 秒大标题，制造高温解腻痛点。
卖点卡：三连卡片，每张只承载一个卖点。
转场：卖点卡之间用快切，CTA 前放慢 0.5 秒。
封面：产品居中 + “夏日冰爽解腻”。
```

## 4. 备选案例

| 案例 | 适合展示 |
|---|---|
| 桌面收纳盒 | 对比前后、包装补全、封面文案 |
| 降噪耳机 | 场景切换、卖点证明、多版本 |
| 迷你筋膜枪 | 使用过程缺口、字幕补全、节奏增强 |
| 护肤品旅行装 | 包装风格、封面方案、卖点顺序调整 |

## 5. 答辩用一句话

```txt
我们故意给系统不完整素材，让评委看到它不是简单生成脚本，而是能判断哪些结构槽位缺素材，并用包装、字幕和素材复用把视频表达补齐。
```
