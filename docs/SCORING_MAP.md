## 最重要的拿分策略

```txt
不要只展示最终视频。
一定要展示中间过程：样例结构 → 新内容映射 → 素材缺口 → 补全策略 → 时间线 → demo。
```

## Demo 必须故意展示素材不足

推荐测试 case：

```txt
新商品：便携咖啡杯
用户素材：产品图 1 张、手持图 1 张、商品文案 1 段

```

这样可以稳定展示缺口识别和补全能力。
